# ManiSkill — Benchmark Guide

Generated by `benchmark-generator` skill. English-only by contract; regenerated on every re-run.

## About

ManiSkill is a large-scale robotic manipulation benchmark built on SAPIEN with a strong focus on GPU-parallel simulation. It ships a gymnasium-compatible API, dense + sparse reward variants, and ~40 registered tasks spanning tabletop (PickCube, PushCube, StackCube), articulated (OpenCabinet, TurnFaucet), dexterous (AllegroHand), mobile manipulation, humanoid, and quadruped scenarios. The SAPIEN backend gives PhysX-5 contact physics, ray-traced rendering, and GPU-side state cloning — the same `env.step(...)` advances thousands of parallel envs on one GPU. Used end-to-end for both Reinforcement Learning (PPO/SAC/TD3 baselines) and Imitation Learning (BC/Diffusion Policy/ACT baselines under `examples/baselines/`); this generated harness wires the IL evaluation track via WebSocket policy server.

## How to use

The skill produced three receipt files at the repo root — `install.md` (how to build), `history.md` (what the skill did), and this file (what the benchmark *is*). The flow below assumes you have already followed `install.md` and have `maniskill-headless` running.

### 1. Enter the container

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it maniskill-headless bash
```

### 2. Pick a task

```bash
python scripts/run_demo.py --list_tasks
```

Any identifier from the printed list (or table above) is a valid `--env_id`.

### 3. IL workflow — stand up a policy server

For a smoke test, use the companion random-policy server (ships with the image):

```bash
python tests/test_random_policy_server.py --port 8765
```

For real evaluation, replace it with any server that speaks the `policy_websocket` protocol and advertises `action_dim=8` in its metadata handshake (the client guard in `scripts/run_eval.py` enforces the match).

### 4. IL workflow — run a single-episode demo

```bash
python scripts/run_demo.py --policy_server_addr localhost:8765 \
    --env_id PickCube-v1 --num_resets 1
```

Writes a per-run dir under `./logs/demo/<env_id>--<YYYYMMDD_HHMMSS>/` containing `demo.log` + (optional) MP4. The `__meta__` envelope (`{v:1, benchmark:"maniskill", task, task_description, phase}`) is injected on every step's payload per the benchmark contract.

### 5. IL workflow — multi-episode eval

```bash
python scripts/run_eval.py --policy_server_addr localhost:8765 \
    --env_id PickCube-v1 --num_trials 10
```

Prints rolling + final success rate across `--num_trials` rollouts. Success follows ManiSkill's `info['success']` boolean.

### 6. RL workflow — train a policy

ManiSkill ships its own RL baselines (PPO/SAC/TD3) under `examples/baselines/`. The native dispatcher script lives at `scripts/train_rl_policy.py` (left in place by env-generator):

```bash
# Native ManiSkill PPO baseline (preferred)
python examples/baselines/ppo/ppo.py --env_id="PickCube-v1" \
    --num_envs=2048 --update_epochs=8 --num_minibatches=32 \
    --total_timesteps=10_000_000

# Or use scripts/train_rl_policy.py if present
python scripts/train_rl_policy.py --config-name ppo \
    env_id=PickCube-v1 total_timesteps=1_000_000
```

For a fast smoke check, set `total_timesteps=5000`, `n_envs=1`, `wandb=null`.

### 7. Demonstration datasets (IL)

ManiSkill provides curated motion-planning + RL-rollout demonstration datasets via HuggingFace. Download:

```bash
python -m mani_skill.utils.download_demo --task PickCube-v1
```

Datasets land under `~/.maniskill/demos/`. Use them with `examples/baselines/{bc,diffusion_policy,act}/` for IL training.

## Troubleshooting

- `ConnectionRefused` on `run_eval.py` / `run_demo.py` → no policy server on the configured port. Start `tests/test_random_policy_server.py --port 8765` first (IL), or launch your own trained-policy server.
- `ValueError: server action_dim=N != expected 8` → server advertises a different dim. Fix the server's `ACTION_DIM` constant or change robot/controller to match.
- `RuntimeError: PhysX GPU not initialized` → re-run the Dockerfile's PhysX warmup: `python -c "import sapien.physx as physx; physx.enable_gpu()"` inside the container.
- Task name not recognized → run `run_demo.py --list_tasks` to see the current list (a task may have been blacklisted in `EVAL_TASK_BLACKLIST`).
- GUI apps fail with `cannot open display` → headless compose profile. Switch to `docker-compose.x11.yaml` after `docker compose down`.
- `Vulkan device 0 not available` → host missing NVIDIA Vulkan ICD. Reinstall NVIDIA Container Toolkit on host.
