# ManiSkill — Install Recipe

Minimum commands to reproduce this benchmark container from a fresh clone. Generated by the `benchmark-env-generator` skill (sub-skill of `env-generator`).

## Host prerequisites

- Docker (>= 24) and the Compose v2 plugin
- NVIDIA driver + NVIDIA Container Toolkit with a GPU visible to `nvidia-smi`
- `vulkaninfo` on the host (SAPIEN-based benchmarks need a working Vulkan ICD at runtime)
- Disk budget for first-run asset download (ManiSkill downloads per-task via `python -m mani_skill.utils.download_asset`)

## Build the image

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cudagl:11.3.1-devel-ubuntu20.04`
Python: `3.10` (managed by `micromamba`, env name `maniskill`)
Pip-installed extras: `mani_skill==3.0.0b22`, `torch`, `policy-websocket` (from YufengJin/policy_websocket), `imageio[ffmpeg]`, `stable-baselines3[extra]`, `hydra-core>=1.3`.

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it maniskill_container bash
```

For an X11 / GUI session (swap the compose profile — container name is shared, only one may run):

```bash
xhost +local:docker
docker compose -f docker/docker-compose.headless.yaml down
docker compose -f docker/docker-compose.x11.yaml up -d
```

## First-run sanity checks (inside the container)

```bash
nvidia-smi
vulkaninfo --summary
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -c "import mani_skill; print(mani_skill.__file__)"
```

The last line must resolve under `/workspace/mani_skill/` — that proves the mounted source is what the interpreter imports (editable install succeeded).

### Optional asset / dataset download

The entrypoint prompts rather than force-downloads. To opt in:

```bash
# In the running container
python -m mani_skill.utils.download_asset PickCube-v1
python -m mani_skill.utils.download_demo PickCube-v1
```

Assets land under `/workspace/.maniskill/` (mounted back to the host).

## Category-specific smoke run

ManiSkill is a **dual-track** benchmark: the repo ships IL-style WebSocket eval scripts **and** an RL sb3 training entrypoint. Both workflows share the same image.

### IL: WebSocket random-policy loop

The image ships with a companion server so the stack is end-to-end runnable without a trained policy:

```bash
# 1. Start the random-policy server (advertises action_dim=8)
docker exec -d maniskill_container \
    micromamba run -n maniskill python tests/test_random_policy_server.py --port 8000

# 2. Wait for the port to open
docker exec maniskill_container micromamba run -n maniskill python -c "
import socket, time
for _ in range(30):
    try:
        socket.create_connection(('127.0.0.1', 8000), timeout=1).close()
        print('ready'); break
    except OSError:
        time.sleep(0.5)
"

# 3. Single-episode demo
docker exec maniskill_container \
    micromamba run -n maniskill python scripts/run_demo.py \
        --env_id PickCube-v1 --policy_server_addr localhost:8000 --num_resets 1

# 4. Eval harness (N episodes, success-rate aggregation)
docker exec maniskill_container \
    micromamba run -n maniskill python scripts/run_eval.py \
        --env_id PickCube-v1 --policy_server_addr localhost:8000 --num_trials 1

# 5. Clean up
docker exec maniskill_container pkill -f test_random_policy_server
```

The random policy never solves the task — a zero success rate plus a clean exit is the expected outcome.

### RL: short training run (sb3 PPO)

```bash
docker exec maniskill_container \
    micromamba run -n maniskill python scripts/train_rl_policy.py \
        --config-name ppo env_id=PickCube-v1 total_timesteps=5000 n_envs=1 wandb=null
```

Available algorithms: `ppo, sac, td3, ddpg, dqn, a2c` (baselines mode: `sb3`). Configs live under `conf/{ppo,sac,td3}.yaml`.

docker compose -f docker/docker-compose.headless.yaml down
