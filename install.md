# ManiSkill — Install Recipe

Minimum commands to reproduce this container from a fresh clone. Generated by `env-generator` skill.

## Host prerequisites

- Docker (>= 24) and the Compose v2 plugin
- NVIDIA driver >= 520 and the NVIDIA Container Toolkit
- A GPU visible to `nvidia-smi`

Run the bundled check before building:

```bash
bash docker/check_prereqs.sh
```

## Build the image

```bash
docker compose -f docker/docker-compose.headless.yaml build
```

Base image: `nvidia/cuda:12.8.1-cudnn-runtime-ubuntu22.04`
Python: `3.9` (managed by `uv` in `/opt/venv`)
Install strategy: `uv-pip-editable` (mani_skill installed from PyPI + editable mount at container start)

## Bring the container up

```bash
docker compose -f docker/docker-compose.headless.yaml up -d
docker exec -it maniskill-headless bash
```

For an X11-enabled session (GUI apps, visualisers):

```bash
xhost +local:docker
docker compose -f docker/docker-compose.x11.yaml up -d
```

Only one of the two profiles may run at a time — they share the container name.

## First-run sanity checks (inside the container)

```bash
nvidia-smi
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
python -c "import mani_skill; print(mani_skill.__file__)"
```

The last line must resolve under `/workspace/ManiSkill/` — this proves that the mounted source is the one the interpreter imports (editable install succeeded).

## Vulkan / SAPIEN GPU rendering

The image includes Vulkan ICD files for NVIDIA (`nvidia_icd.json`, `nvidia_layers.json`). The compose file sets `VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/nvidia_icd.json`. PhysX GPU binaries are downloaded during build (see Dockerfile layer 14).

Quick headless rendering test:

```bash
python -m mani_skill.examples.demo_random_action -e PickCube-v1 --render-mode=rgb_array --record-dir=/tmp/videos
```

## Setuptools note

`sapien`'s transitive dependency (`triton`) upgrades `setuptools` to 82+ during install, which drops `pkg_resources` and breaks `mani_skill` import. The Dockerfile pins `setuptools>=62.3,<81` twice — before and after the main install — to ensure the final venv state is compatible.

## Stop / clean up

```bash
docker compose -f docker/docker-compose.headless.yaml down
```
